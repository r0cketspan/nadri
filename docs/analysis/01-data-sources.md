# 01. 추가 데이터 원천 조사 (TourAPI 외)

> 작성일 2026-10-25. 웹 검색 기반 1차 조사 — `미확인` 항목은 연동 작업 전에 공식 페이지에서 다시 확인한다.
> 결정: **MVP는 TourAPI만 사용**하고, 아래 4곳은 **확장 데이터 원천(추후)** 으로 아키텍처에 표시해 둔다. (requirements FR-49)

|---|---|---|

| 투어고 (한국문화관광연구원) | 관광 통계·정책·보고서 | 통계 참고용 |

## 3. 크롤링에 대해
- 위 원천은 모두 API·파일로 제공되므로 **크롤링은 쓰지 않는 것을 기본**으로 한다.
- 크롤링이 꼭 필요하면 대상마다 `robots.txt`·이용약관·저작권(블로그·리뷰·뉴스 본문은 대부분 재사용 불가)을 먼저 확인하고, 출처 표기가 가능한 공식 페이지(지자체 축제 공식 사이트 등)로 한정한다.

## 4. 연동 시 고려사항 (G3·구현 때 참고)
- 수집은 `ingest`에 원천별로 추가한다. 실시간성 데이터(혼잡도)는 `tour-tools`의 실시간 툴로 노출하는 쪽이 맞다.
- 원천마다 **출처·기준일·라이선스 표기**를 위키 frontmatter와 답변에 그대로 유지한다.
- 같은 장소가 여러 원천에 있으면 어느 원천을 우선할지(병합 규칙)를 정해야 한다.
- 원천별 일일 호출 한도를 따로 관리한다.
