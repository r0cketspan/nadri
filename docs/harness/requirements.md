## 1. 배경 / 목표

### 배경
- 한국관광공사 TourAPI 4.0(`KorService2`) 공공데이터를 바탕으로, 웹·모바일 브라우저에서 쓰는 관광 질의응답 챗봇을 만든다. [CL 서두], [AN §11]
- 공공데이터에 표(수치) 데이터가 많아 Graph RAG만으로는 수치 질문에 약하다. 그래서 정형 조회와 위키+Graph RAG를 함께 쓰는 하이브리드 구조로 정했다. [AN §0, §3.4]
- 이 프로젝트는 tool calling, 벡터DB·임베딩, 추론 파이프라인, 컨테이너 배포, 프롬프트 캐싱 역량을 보여 주는 목적도 함께 가진다. [AN §8]

### 목표
1. 관광 사실(운영시간·요금·위치 등)을 공공데이터 근거로 출처·기준일과 함께 답한다. [TS §4.2], [AN §11]
2. 데이터 변경분만 반영하는 현행화 파이프라인으로 답변 근거를 최신으로 유지한다. [TS §3.3]
3. 승인된 사용자에게 스트리밍 채팅, 대화 이력, 음성 입출력(PTT STT/TTS)을 PC·모바일 브라우저(PWA)로 제공한다. [TS §1, §6, §8], [U]
4. 관리자가 백오피스에서 가입 승인·한도 추가·사용량을 관리한다. [U]
5. OpenAI 비용을 통제한다(캐싱·모델 분리·사용자별 한도). [TS §10], [U]
6. 성공 기준: 골든 Q&A 평가셋의 정답률·근거 일치율과 E2E 시나리오 통과. MVP에서는 **측정·기록만** 하고 목표 수치는 PoC 결과를 보고 정한다. [TS §11], [U Q15]
